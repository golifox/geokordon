# 0.6.0: страны, шаблон контейнеров, dnf

Решения владельца от 2026-11-17: команда `config`, dnf с тестами и дымовым прогоном на Rocky 9, «Amnezia» убирается из описаний (README, справка, GitHub).

## Конфиг

`/etc/geokordon/config`, строки `ключ=значение`; читается разбором, не через `source`. Без файла действуют значения по умолчанию, то есть поведение 0.5.0.

| Ключ | По умолчанию | Значение |
| --- | --- | --- |
| `countries` | `ru` | коды стран ipdeny через запятую: `ru,by` |
| `containers` | `^amnezia` | расширенное регулярное выражение для имён контейнеров: их порты открыты, их трафик идёт через WARP |

- `geokordon config` печатает значения.
- `geokordon config countries ru,by` и `geokordon config containers '^(amnezia|3x-ui)'` проверяют значение (код из двух латинских букв; регулярное выражение, которое понимает `grep -E`), записывают его и сразу выполняют `update`. Если обновление не удалось, конфиг возвращается как был, как и прямой список.
- Через `-H` команда работает на нескольких серверах сразу.

## Геоблок по странам

- Списки скачиваются для каждой страны: `$CACHE/<cc>4.zone` и `<cc>6.zone`; кэш `ru` из прошлых версий подходит как есть.
- Наборы nft называются `geo4` и `geo6` вместо `ru4` и `ru6`; правила те же.
- Проверка загрузки: каждая строка — префикс, и не меньше половины префиксов в кэше. Для первой загрузки страны без кэша нужно не меньше 10 префиксов IPv4. Порог 1000/200 из 0.3.1 уходит: у маленьких стран бывает около 100 префиксов. Если IPv6-списка у страны нет (ipdeny отвечает 404), он не нужен.
- Если после загрузки у какой-то страны из конфига нет IPv4-списка ни свежего, ни в кэше, обновление падает, и текущие правила остаются.
- `status` показывает страны и шаблон; сообщения говорят «blocked countries» вместо «RU».

## dnf

- `need_packages` работает через apt (Debian, Ubuntu) или dnf (Rocky, Alma, RHEL, Fedora). Имена пакетов одинаковые: `nftables`, `curl`, `wireguard-tools`.
- firewalld не трогаем: у нас своя таблица `inet geokordon`.
- Тесты: bats в `debian:12` и `rockylinux:9`. Дымовой прогон `install` → `status` → `allow` → `config` → `remove` в контейнере Rocky 9 с systemd (`test/smoke-rocky.sh`); его же можно запустить локально.

## Описания

README, справка и комментарии говорят о VPN-сервере в Docker вообще; Amnezia остаётся примером и значением по умолчанию. Описание репозитория на GitHub меняется через `gh repo edit` при релизе.

## Вне объёма

Alpine и другие системы без systemd, IPv6 в WARP, `.deb`, Homebrew.

## Риски

- Блокировка страны, откуда заходит администратор, закрывает ему всё, кроме SSH и портов контейнеров. Так же, как сейчас с `ru`.
- `firewall-cmd --reload` в старых версиях firewalld мог сбрасывать весь набор правил nft. На RHEL 9 и новее он трогает только свою таблицу. Если таблица пропадёт, её вернёт следующее обновление по таймеру.

CI зелёный, включая Rocky; оба сервера обновлены до 0.6.0 без изменений в поведении (страна `ru`, шаблон `^amnezia`).
